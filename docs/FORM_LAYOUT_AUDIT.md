# 입력 화면 레이아웃 점검

점검일: 2026-09-24

## 수정 내용

- 수의계약·입찰 계약 요청: 보증보험 선택과 추가 입력을 서로 다른 행에 배치하고 지급비율·보증률 숫자 입력과 % 단위를 묶었다.
- 공통 상세 입력 표: 입력 요소 간 간격과 줄바꿈, 조건부 영역의 전체 폭, 파일 선택 영역의 폭을 정리했다.
- 비고 등 다중 행 입력: 전체 폭과 최소 높이 96px을 적용했다.
- 날짜/시간: 날짜와 시·분 선택을 묶고 시간 선택 폭을 확보했다. 입찰 계획, 수의계약 계획·견적 요청, 관련 입찰 팝업에 적용했다.
- 협력업체 첨부 목록: 세로 배치 영역의 넘침을 해소하고 파일명·버튼의 줄바꿈을 보완했다.
- 하단 작업 버튼은 좁은 폭에서 줄바꿈하며 우측 작업 그룹 정렬을 유지한다. 넓은 공고 요약 표는 내부 가로 스크롤을 허용한다.
- 팝업 소스 변경 후 번들을 재생성했다.

## 브라우저 검증

Chrome에서 상세 입력 표를 사용하는 본문 페이지 35개와 팝업 소스 35개를 각각 1280·1440·1920px에서 검사했다(210개 조합). 공통관리, 협력업체, 사전견적, 발주요청·계획, 수의계약, 입찰, 계약, 기준정보의 해당 입력 화면을 포함한다.

보이는 입력 셀의 가로 넘침, 입력·선택·버튼·파일 선택·단위 묶음의 셀 밖 이탈, 비고란 높이 부족을 측정했다. 자료실·공지사항·협력업체 질문 작성은 작성 화면을 직접 열어 확인했다. 최종 210개 조합에서 해당 문제는 검출되지 않았다.

추가로 수의계약·입찰 계약 요청의 지급조건 3종과 보증보험 필요/불필요 조합 12건, 입찰계획의 직접 공고·현장설명 사용 상태를 확인했다. 수의계약 요청 및 입찰계획의 대표 화면은 스크린샷으로 정렬도 확인했다.

팝업 35개는 독립 소스 화면의 기본 입력 레이아웃을 검사한 범위이며 모든 업무 상태와 팝업 실행 흐름 전체를 검증했다는 의미는 아니다.
