## 0. 원칙 (요약 — 상세는 작업지침서.md)
- 화면설계(PPTX)에 그려진 화면 구성·항목·문구·배치를 **추론하거나 임의로 바꾸지 않고 그대로** 재현한다.
- 시각 스타일(색상·폰트·여백·헤더/사이드바/버튼 등 공통 컴포넌트)은 `../DESIGN_GUIDE.md`를 그대로 따른다.
- 이 둘이 충돌하는 것처럼 보이면: **레이아웃/항목/문구 = 화면설계 그대로**, **색·타이포·공통 UI 부품의 생김새 = DESIGN_GUIDE** 라는 원칙으로 판단한다.
- **기능(업무 로직/유효성 검증/서버 연동)은 만들지 않는다. 화면과 화면을 실제 링크로 이어주는 것까지만 한다.** (탭 전환, 모달 열기/닫기 등 디자인을 보여주기 위한 수준의 인터랙션은 포함)
- 루트 `index.html`을 로그인 및 유일한 실행 진입점으로 사용하며, 이후 실제 화면 속 메뉴·버튼·행 클릭을 통해 화면과 화면을 탐색한다.
- **모든 업무 화면은 `modules` 아래 모듈별 폴더 안에 있다.** 폴더명은 PPTX 파일 번호와 1:1 대응하며, 공통 자산은 `assets`, 문서와 원본 자료는 `docs`에 분리한다.
