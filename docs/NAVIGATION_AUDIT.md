## 팝업·예시 상태 전달

- 문서 팝업을 열어도 목록 화면이 상세 화면으로 전환되거나 URL의 선택 상태가 바뀌지 않도록 분리했다. 같은 화면 안에서 여는 게시판형 상세는 선택 게시물을 URL에 계속 유지한다.
- 게시물의 계약방법·낙찰방법·번호·건명은 문서 팝업에도 반영한다. 견적번호·업체명·견적 차수는 해당 링크와 팝업에 전달한다.
- 07-2 / 74에 정의된 수의시담 견적 요청 상세 페이지를 추가했다. 견적서 팝업의 공통 서식은 07-2 / 58을 사용한다.
- 07-1 / 16, 07-2 / 15·25의 밑줄 있는 공통 템플릿명은 기준정보의 기존 예시 내용을 읽기 전용 팝업으로 확인하게 했다. 원본에 별도 미리보기 도면은 없으므로 새 업무 항목은 추가하지 않았다. 선택 버튼과 내용 확인을 분리했다.
- 10 / 7·10에서 팝업으로 그려진 코드/공통 서류 등록·수정을 복원했다. 기존 독립 페이지 파일은 다른 참조를 손상하지 않도록 유지하고, 이전 일괄 변환 도구에서 해당 두 항목을 제외했다.

## 설계 경계

00 / 13의 로그인 횟수는 밑줄이 있으나 클릭 목적지, 상세 목록 또는 팝업 설계가 없다. 이 통계 숫자에는 임의의 목적지를 만들지 않았다. 02 / 17의 공고번호 역시 별도 문서 호출 설명이 없어 건명과 같은 공고 정보로 연결했다.

## 검증

- `tools/audit_navigation_design.py`: 전체 PPTX 링크 서식·Description 추출.
- `tools/test_navigation_links.cjs`: 식별번호/제목 열 구분, 번호의 문서 팝업과 제목의 상세 목적지, 목록 유지, 견적 차수, 기준정보 팝업 및 개찰 전 접근 제한 확인.
- `tools/test_conditional_ui.cjs`: 전체 페이지 초기화, 팝업 대상 및 조건부 UI 확인.
- `tools/test_prototype_records.cjs`: 예시 게시물·상태 전달 회귀 확인.
