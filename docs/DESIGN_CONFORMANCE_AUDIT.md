## 검증 범위

315개 HTML의 위 구조 규칙을 검사했다. 145개 화면의 스크립트 초기화 및 조건부 표시, 예시 게시물 연결, 번호/건명별 탐색은 기존 DOM 회귀검사로 확인한다. 새 검색 액션 3개 화면의 초기화도 별도로 확인했다. JavaScript 구문과 diff 공백 오류를 검사했다.
