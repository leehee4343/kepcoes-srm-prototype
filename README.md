# 켑코이에스(주) 전자입찰시스템(SRM) 프로토타입

화면설계(PPTX)를 기준으로 제작 중인 **디자인 전용 HTML 프로토타입**입니다. 업무 로직·데이터 처리는 구현하지 않으며, 화면 간 이동만 실제 링크로 연결되어 있습니다.

## 시작하기
로그인 화면이 유일한 진입점입니다.
```
01_협력업체창구_로그인전/SRMLogin.html
```
브라우저로 위 파일을 열면 로그인 화면부터 시작해 실제 메뉴·버튼을 눌러가며 이어지는 화면들을 확인할 수 있습니다.

## 폴더 구조
화면설계 PPTX 파일 번호와 1:1로 대응하는 모듈별 폴더 구조입니다.

```
/css, /js, /assets        공통 스타일·스크립트·이미지
/00_공통관리
/01_협력업체창구_로그인전
/02_협력업체창구_로그인후
/03_대시보드
/04_사전견적관리 ~ /10_기준정보관리   (진행 중)
```

- [`DESIGN_GUIDE.md`](DESIGN_GUIDE.md) — 색상·타이포·레이아웃·컴포넌트 디자인 시스템 규격

## 원칙
1. 화면설계(PPTX)의 구성·항목·문구는 추론하지 않고 그대로 재현한다.
2. 색상·폰트·간격 등 공통 UI 스타일은 `DESIGN_GUIDE.md`를 따른다.
3. 업무 로직은 만들지 않고, 화면과 화면을 실제 링크로 이어주는 것까지만 한다.
