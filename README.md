# 켑코이에스(주) 전자입찰시스템(SRM) 프로토타입

화면설계(PPTX) 362슬라이드(작업대상 318화면)를 기준으로 제작한 **디자인 전용 HTML 프로토타입**입니다. 업무 로직·데이터 처리는 구현하지 않으며, 화면 간 이동만 실제 링크로 연결되어 있습니다. 00번(공통관리)부터 10번(기준정보관리)까지 전체 모듈이 완성되었습니다.

## 시작하기
루트 로그인 화면이 유일한 진입점입니다.
```
index.html
```
브라우저로 위 파일을 열면 로그인 화면부터 시작해 실제 메뉴·버튼을 눌러가며 이어지는 화면들을 확인할 수 있습니다. 프로토타입 로그인 아이디 `1`은 협력업체 대시보드, `2`는 내부 관리자 대시보드로 이동합니다.

## 폴더 구조
실행 코드, 업무 화면, 프로젝트 문서와 원본 참고자료를 역할별로 분리했습니다.

```
/
├─ index.html                 # 로그인 및 실행 진입점
├─ README.md                  # 프로젝트 안내
├─ DESIGN_GUIDE.md            # 공통 UI 디자인 시스템
├─ assets/                    # 공통 프런트엔드 자산
│  ├─ images/
│  ├─ scripts/
│  └─ styles/
├─ modules/                   # 화면설계 번호별 업무 화면
│  ├─ 00_공통관리/
│  ├─ 01_협력업체창구_로그인전/
│  ├─ 02_협력업체창구_로그인후/
│  ├─ 03_대시보드/
│  ├─ 04_사전견적관리/
│  ├─ 05_발주계약요청/
│  ├─ 06_발주계획/
│  ├─ 07-1_수의계약관리/
│  ├─ 07-2_입찰관리/
│  ├─ 08_계약관리/
│  ├─ 09_협력업체관리/
│  └─ 10_기준정보관리/
└─ docs/                      # 설계·작업 문서
   └─ reference/              # PPTX·XLSX·디자인 원본
```

## 작업 문서 (Single Source of Truth)
- [`작업진행현황.md`](docs/작업진행현황.md) — Phase(모듈)별 진행률과 변경 이력
- [`SCREEN_LIST.md`](docs/SCREEN_LIST.md) — 화면설계 PPTX 362슬라이드 전수 체크리스트
- [`작업지침서.md`](docs/작업지침서.md) — 화면설계를 그대로 재현하기 위한 작업 규칙(어떤 AI 도구가 이어받아도 동일하게 작업하도록)
- [`DESIGN_GUIDE.md`](DESIGN_GUIDE.md) — 색상·타이포·레이아웃·컴포넌트 디자인 시스템 규격

## 참고 원본 자료
- `docs/reference/[참고] 메뉴구조도 및 기능명세서.xlsx`
- `docs/reference/[참고] 화면설계(00~10).pptx` — 화면설계 원본 (재현의 기준)
- `docs/reference/[참고]디자인 샘플.jpeg`

## 원칙
1. 화면설계(PPTX)의 구성·항목·문구는 추론하지 않고 그대로 재현한다.
2. 색상·폰트·간격 등 공통 UI 스타일은 `DESIGN_GUIDE.md`를 따른다.
3. 업무 로직은 만들지 않고, 화면과 화면을 실제 링크로 이어주는 것까지만 한다.

자세한 내용은 `docs/작업지침서.md`를 참고하세요.
