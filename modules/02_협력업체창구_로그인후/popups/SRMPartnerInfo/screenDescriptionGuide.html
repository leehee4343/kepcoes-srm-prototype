화면설계 Description

협력업체 정보 확인

1 
협력업체는 담당자를 여러 명 등록할 수 있음

단, ‘기본 담당자’는 협력업체 신청 시 입력한 담당자임

기본 정보 수정 요청

2 
바로 수정되지 않고, 관리자의 내용과 서류검토 후 승인을 통해 수정됨

단, 관리자의 거절 시 이전 승인되었을 때의 상태로 되돌아와야 한다는 것을 염두에 둘 것(개발자 대상 주요 전달사항)

임시테이블에 저장한 후 관리자에 의해 승인되면 반영.
또한 거절되면 원복(롤백) 해야 함
3 
고객 통보 : MSG-007

담당자 정보 추가/수정

4 
협력업체 신청 시 등록한 담당자(기본 담당자)는 삭제할 수 없음(정보 수정은 가능함)
5 
협력업체에 기본 담당자는 한 명만 존재할 수 있음.

Alert ‘기본 담당자가 이미 설정되어 있습니다. 기본 담당자는 반드시 한 명이어야 합니다.’

기본 담당자로 선택한 경우 교체되어야 함

비밀번호 변경

6 
비밀번호 변경 후 Alert 제공 후 다시 로그인 유도할 것

Alert
“비밀번호가 변경되었습니다. 다시 로그인해주세요.”
