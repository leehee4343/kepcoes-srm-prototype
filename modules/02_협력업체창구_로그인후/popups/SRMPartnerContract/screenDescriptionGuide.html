화면설계 Description

검색/조회

1 
해당 협력업체가 계약(수의계약, 입찰) 건 검색/조회
2 
계약방법/낙찰자 선정방법 별 검색 : 당연히 ‘수의계약’이 포함됨
3 
진행상태 정의 : 노란 부분 참조
4 
검색 구분 : 계약번호, 계약명

계약 정보 · 계약 변경 내역 상세보기

1 
변경 사유에 따라 아래의 입력 항목이 노출됨
2 
‘계약금액’ 변경 시 노출
3 
‘납기일/공사기간’ 변경 시 노출

계약 관련 서류 제출

1 
(제출 후 관리자에 의해 확정되기 전) 해당 공고에 설정된 ‘계약이행 보증금률’, ‘선금이행 보증금률’, ‘하자이행 보증금률’을 보여줌
2 
만약 ‘발급 필요 없음’으로 설정된 경우 제출대상이 아니라는 메시지를 제공함
3 
제출 후 관리자에 의해 확정된 경우 이와 같이 표시함
4 
사업이 진행되는 경과에 따라서 단계적으로 해당되는 보증보험 증권을 제출할 수 있음
진행상태를 ‘계약요청(서류제출 완료)’로 변경
