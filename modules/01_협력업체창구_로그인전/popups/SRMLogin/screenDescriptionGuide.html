화면설계 Description

로그인

1 
켑코이에스 또는 전자입찰시스템(SRM)을 홍보/표현해 줄 수 있는 핵심 메시지 제공 필요
2 
로그인 문의를 담당해 줄 직원과 연락처 제공 필요
3 
협력업체(관리자에 의해 승인된)만 로그인 가능

승인된 협력업체일지라도 관리자에 의해 사용 여부가 N(사용 안 함)인 경우 로그인 불가
4 
입찰공고 내역서: 뒤 페이지 팝업 호출

아이디 찾기(팝업)

팝업으로 사업자등록번호(숫자)가 아이디임을 안내함

비밀번호 찾기(팝업)

1 
협력업체는 다수(N)의 담당자가 등록될 수 있으며, 등록된 담당자의 정보와 일치하면 비밀번호 찾기 제공(매칭된 담당자의 이메일)
2 
이메일 주소는 일부를 마스킹 처리할 것

마스킹 규칙 : 개발자 자유
임시 비밀번호 발송 : 비밀번호 생성 규칙(영문/숫자/특수기호 조합 8~20자) 기준을 준수하는 범위에서 개발자 자유
3 
고객 통보 : MSG-002
