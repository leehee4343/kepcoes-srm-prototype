화면설계 Description

심사/평가

화면설계 07-2 · 슬라이드 47

1 
심사/평가가 없는 경우(낙찰자 선정방법이 ‘최저가’인 경우) 해당 탭 클릭 시 Alert 제공

Alert
‘본 입찰공고는 낙찰자 선정방법이 ‘최저가’ 방식으로 심사/평가 대상이 아닙니다.’
2 
진행상태가 ‘입찰 참여 완료’ 건만 보임(그 외에는 평가 대상이 아님)
3 
심사완료 처리 후에는 더 이상 평가 점수가 수정되지 않음

진행상태를 ‘심사완료’ 상태로 변경
4 
심사완료 처리 후,
낙찰자 선정방법이 ‘제한적 최저가 입찰’, ‘2단계 경쟁입찰(규격/가격 분리)’인 입찰 건의 경우 가격투찰 안내하기 버튼 제공

뒤 페이지 ‘가격투찰 안내하기’ 팝업 호출
5 
낙찰자 선정방법이 ‘제한적 최저가 입찰’, ‘2단계 경쟁입찰(규격/가격 분리)’인 경우 심사/평가 후 적격 판정을 받은 업체가 2개 미만일 경우 해당 영역 제공

유찰(재공고)을 처리할 수 있음
‘유찰(재공고) 처리하기’ 팝업 호출(앞 페이지 참고)

심사/평가

화면설계 07-2 · 슬라이드 49

7 
심사/평가를 진행하기 전에는 당연히 평가점수는 노출될 수 없음

‘심사/평가전’으로 표시
8 
뒤 페이지 심사/평가하기 팝업창 호출 

당연히,
심사완료 처리 후(진행상태 ‘심사완료’)에는 더 이상 평가 점수를 등록/수정할 수 없음

심사/평가 > (가격투찰 안내하기)

화면설계 07-2 · 슬라이드 51

9 
낙찰자 선정방법이 ‘제한적 최저가 입찰’, ‘2단계 경쟁입찰(규격/가격 분리)’인 입찰 건의 경우(서류와 가격을 분리 제출하지 않음)

규격(기술) 평가 후 ‘적격’인 업체를 대상으로 가격투찰 일정을 안내해야 함 

물론, 투찰일정은 ‘입찰계획 등록’ 시 설정되어 있지만 변경의 여지가 있을 수 있기 때문에 해당 기능을 제공함
10 
입찰계획 당시의 ‘가격 투찰 기간’ 정보 제공
11 
가격 투찰 기간의 변경이 필요한 경우 활용함(아래의 기간 선택 활성화)

변경 값이 저장(업데이트)되어야 함
12 
규격(기술) 심사/평가 결과 적격인 협력업체만 ‘가격 투찰’ 대상이 됨
13 
발송 제목/내용을 자동 완성해 주지만, 수정해서 보낼 수도 있음

내용 중 ‘가격 투찰 기간’은 위의 설정된 값에 따라서 자동 완성해 줌

심사/평가 > (가격 투찰 안내하기)

화면설계 07-2 · 슬라이드 52

유찰(재공고) 처리하기

화면설계 07-2 · 슬라이드 46

19 
유찰 처리 시, 

공고 구분을 ‘재공고(1차)’, ‘재공고(2차)’ 형태로 생성하고

본 입찰계획 당시 등록/설정된 정보를 모두 복사해서 ‘입찰계획 현황’ 메뉴에 새로운 공고 번호로 복사해주는 기능

단, 낙찰자 선정방법이 ‘제한적 최저가 입찰’, ‘적격심사’이면서(예비가) 
+
유찰 처리 시점이 개찰 후인 경우

‘예비가 등록/설정’을 반드시 다시 해야 함(예비가는 복사하지 않고 넘김)
