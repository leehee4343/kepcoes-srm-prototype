화면설계 Description

입찰 참여현황

화면설계 07-2 · 슬라이드 42

1 
제출상태 정의

작성중(미제출) : 현재 작성중인 상태

입찰 서류 제출 완료 : 입찰 서류만 제출 완료한 상태(투찰하지 않음)

가격 투찰 완료 : 가격 투찰만 완료한 상태

입찰 참여 완료 : 입찰 서류 제출 완료 + 가격 투찰을 완료
**단, 낙찰자 선정방법이 ‘제한적 최저가 입찰’, ‘2단계 경쟁입찰(규격/가격 분리)’ 입찰인 경우에는 서류만 제출해도 입찰 참여 완료가 되어야 함**

입찰 포기 : 협력업체가 입찰을 포기한 상태
2 
입찰에 참여한 업체(‘입찰 참여 완료’ 상태)가 2개 미만인 경우 
유찰 처리할 수 있음(해당 영역 제공)

유찰 처리 시 공고 구분을 ‘재공고(1차)’, ‘재공고(2차)’ 형태로 생성하고

본 입찰계획 당시 등록/설정된 정보를 모두 복사해서 ‘입찰계획 현황’ 메뉴에 새로운 공고 번호로 복사해주는 기능

뒤 페이지 팝업 참조

단, 낙찰자 선정방법이 ‘제한적 최저가 입찰’, ‘적격심사’이면서(예비가) 유찰 처리 시점이 개찰 후인 경우에는 ‘예비가 등록/설정’을 다시 해야 함

3

5 
본 입찰에 설정된 담당자에게 메일이나 메시지 발송
